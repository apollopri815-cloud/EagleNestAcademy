# Eaglenest Academy School Website

A responsive 6-page website for a fictional school, **Eaglenest Academy**, built as a personal practice project to demonstrate front-end web development skills.

**Live demo:** [https://github.com/apollopri815-cloud/EagleNestAcademy ]

   ![Homepage screenshot](screenshots/homepage_screenshot.png)

## Pages

| Page | Description |
|------|-------------|
| Home (`index.html`) | Landing page introducing the school |
| About | The school's story, mission and values |
| Academics | Programmes and subjects offered |
| Admissions | How to apply and admission requirements |
| Student Life | Activities, clubs and school life |
| Contact | Contact details and enquiry form |

## Design

- **Colour theme:** sky blue and green
- **Typography:** Montserrat and Century Gothic
- **Layout:** responsive, designed to work on phones, tablets and desktops

## Built With

- HTML5
- CSS3
- JavaScript

3. Open `index.html` in your browser.
